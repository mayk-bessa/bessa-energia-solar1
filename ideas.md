## Design Philosophy Escolhido

### Design Movement
**Modern Energy Minimalism** - Uma abordagem contemporânea que combina minimalismo com energia visual, refletindo a natureza dinâmica da energia solar.

### Core Principles
1. **Clareza Funcional**: Cada elemento comunica um propósito claro - economia, confiabilidade, inovação
2. **Dinamismo Controlado**: Movimento sutil que evoca energia sem ser caótico
3. **Confiança Profissional**: Design que transmite expertise e solidez, não apenas marketing agressivo
4. **Acessibilidade Prioritária**: Contraste alto, hierarquia clara, navegação intuitiva

### Color Philosophy
- **Laranja Energético** (#FF6B35): Representa energia, inovação, otimismo - a força do sol
- **Azul Profundo** (#1E3A8A): Confiança, estabilidade, profissionalismo
- **Branco e Cinzas Neutros**: Clareza, espaço respirável, foco no conteúdo
- **Intenção Emocional**: Laranja evoca ação e esperança; azul transmite confiança e segurança

### Layout Paradigm
- **Assimétrico com Fluxo Diagonal**: Seções alternadas entre esquerda/direita para evitar monotonia
- **Blocos Modulares**: Cada seção é independente mas conectada visualmente
- **Espaço Negativo Generoso**: Muito espaço em branco para respiração visual
- **Hierarquia Vertical Clara**: Fluxo natural de leitura com pontos de atenção estratégicos

### Signature Elements
1. **Linhas Diagonais Sutis**: Dividers com ângulos que evocam painéis solares
2. **Ícones Laranja Circulares**: Badges com ícones para destacar benefícios
3. **Cards com Sombra Elevada**: Profundidade sutil que destaca conteúdo importante

### Interaction Philosophy
- **Hover States Responsivos**: Botões e cards ganham elevação ao passar o mouse
- **Transições Suaves**: Fade-ins e slides para elementos ao scroll
- **Feedback Visual Imediato**: Cliques e interações com feedback visual claro
- **Micro-interações**: Pequenas animações que recompensam o usuário

### Animation Guidelines
- **Entrada de Seções**: Fade-in com slight slide-up ao entrar na viewport
- **Hover de Botões**: Elevação suave (box-shadow) + mudança de cor
- **Scroll Animations**: Parallax sutil no hero, fade-in progressivo de elementos
- **Transições**: 300-400ms de duração, easing ease-out para naturalidade

### Typography System
- **Display Font**: Montserrat Bold (700) para headlines - forte, moderna, energética
- **Body Font**: Inter Regular (400) para corpo - legível, profissional, neutra
- **Hierarchy**:
  - H1: Montserrat 700, 48px, line-height 1.2
  - H2: Montserrat 600, 32px, line-height 1.3
  - H3: Montserrat 600, 24px, line-height 1.4
  - Body: Inter 400, 16px, line-height 1.6
  - Small: Inter 400, 14px, line-height 1.5
